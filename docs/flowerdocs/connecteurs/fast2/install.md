To use FlowerDocs injection tasks within Fast2, it is necessary to add the FlowerDocs connnector to Fast2 libraries:

- add library `flower-docs-fast2p8-connector-2.8.3-bundle.jar` in the folder _lib_ of the installation directory
- restart Fast2
