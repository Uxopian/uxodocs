Add this XML block at the same level as the `hiddenRequest`. You can also hide certain results columns to make your search results more elegant:

<br/>

```xml
<property name="hiddenColumns">
	<list>
		<value>status</value>
		<value>classid</value>
	</list>
</property>

```
