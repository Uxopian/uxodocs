## Description

The lasso feature allows a user to retrieve a text in the open document. For example, this text will be retrievable for automatically filling the text fields.

## Use

The lasso feature can be used with our Javascript API. Instruction to use it can be found [here](/docs/arender/development/apis/web-ui/javascript/js-api).
