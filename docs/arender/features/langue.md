ARender is translated into 13 languages:

Arabic, German, English, Spanish, French, Italian, Portuguese, Chinese, Brazilian Portuguese, Hebrew, Russian, Polish, Japanese.

It is also possible to add new languages to the ARender deployment by adding a label file.

To do this, copy the English translation of the labels located in arondor-arender-hmi-spring-boot-{{version}}.jar\BOOT-INF\classes\labels\ARenderLabels_en.properties and create your own translation by renaming it with the locale you want to see supported.
