## Topics covered

The guide covers the following ARender viewer features:

- **Overview** — Viewing, File actions, Editing, Advanced features
- **Viewing** — Navigation, Thumbnails, Display actions, Bookmarks, Signature, Layers, Video
- **File actions** — Print, Download, Search, Accessibility, Text selection, Quick menu, Open a document
- **Editing** — General, Sticky note, Highlight rectangle, Freetext, Arrow, Highlight text, Audio, Hyperlink, Annotation browser, Slider
- **Advanced features** — Document builder, Redact, Document comparison, Video annotation
