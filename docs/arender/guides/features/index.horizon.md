# User guide

ARender Horizon includes a visual user guide for end users. Each task is shown on a screenshot with numbered markers, and each step of the text points to its marker.

:::info Version
This edition describes **ARender Horizon 2026.5**. The Horizon interface evolves from one release to the next, and the guide follows it. The version is printed on the cover and at the bottom of every slide, so a downloaded copy always says which release it covers.
:::

## Topics covered

1. **Get started**: the screen at a glance, open a file, show or hide the side panel
2. **Move around a document**: pages, thumbnails, table of contents, links
3. **Adjust the view**: zoom, full screen, rotate a page
4. **Find, select and copy text**: search, go from one match to the next, select and copy
5. **Annotate**: highlight, underline, strike through, colours, rectangles, circles, arrows, freehand, text boxes, move, resize, duplicate and delete
6. **Review with comments**: comment on a point or a zone, reply, accept, reject, close and re-open, edit and delete, the Comments list
7. **Print and download**
8. **Work with several documents**: sets of documents, folders, emails and attachments, search a set, documents side by side
9. **Spreadsheets, videos and images**: spreadsheet views, sheets and cells, video, audio, scans and photos
10. **Keyboard shortcuts and FAQ**
