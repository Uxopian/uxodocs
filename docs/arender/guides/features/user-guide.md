# User guide

ARender includes a comprehensive visual user guide that walks through all viewer features with screenshots and step-by-step instructions.

## Topics covered

The guide covers the following ARender viewer features:

- Navigation and page browsing
- Zoom controls
- Page rotation
- Full-text search
- Text selection and copy
- Annotations (sticky notes, arrows, shapes, freehand drawing)
- Redaction
- Document comparison
- Document builder
- Print
