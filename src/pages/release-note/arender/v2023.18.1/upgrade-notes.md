## 📦 Product

### Upgrade Instructions

This is a patch release on top of v2023.18.0. To upgrade:

1. Replace the ARender HMI and Rendition Server binaries with the v2023.18.1 versions from the [download section](../release-notes/#download).
2. No configuration changes are required.
3. Restart the services.

If you are upgrading from a version prior to v2023.18.0, please refer to the [v2023.18.0 upgrade notes](../../v2023.18.0/upgrade-notes) first.
