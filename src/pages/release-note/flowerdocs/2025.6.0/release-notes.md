## Overview

Version 2025.6.0 is a minor release that includes security fixes. It also includes the update of the ARender viewer to version 2023.22.0.

### 💻 ARender version update to 2023.22.0

The ARender viewer embedded in FlowerDocs has been updated to version 2023.22.0. This update includes several fixes and improvements.

For more details, you can check the ARender release notes [here](/release-note/arender/v2023.22.0/release-notes).
